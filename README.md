# Oxford 3000 — E Kelimeleri

Oxford 3000 listesindeki E harfiyle başlayan kelimeleri (resmi American Oxford 3000 listesindeki 162 kelime; Türkçe anlam, zıt anlam, örnek cümle) çalışmak için tarayıcıda çalışan küçük bir uygulama. Kurulum gerektirmez; `index.html` dosyasını açmak yeterli.

## Modlar
- **Kartlar** — çevir, anlamı ve zıt anlamı gör, bildim / bilemedim de
- **Quiz** — İngilizce → Türkçe, Türkçe → İngilizce, zıt anlam
- **Eşleştirme** — kelimeleri zıt anlamlarıyla (ya da Türkçeleriyle) eşleştir
- **Yazma** — Türkçesini gör / dinle, İngilizcesini yaz
- **Liste** — arama, seviye filtresi, telaffuz

İlerleme tarayıcıda (localStorage) saklanır. Zayıf kelimeler daha sık sorulur.

## GitHub Pages'te yayınlama
1. GitHub'da yeni bir depo aç ve bu klasördeki dosyaları yükle.
2. Settings → Pages → Source: `main` dalı, `/ (root)`.
3. Birkaç dakika sonra `https://<kullanıcı-adın>.github.io/<depo-adı>/` adresinde açılır.

Kelime eklemek ya da düzeltmek için `words.js` dosyasını düzenle.
